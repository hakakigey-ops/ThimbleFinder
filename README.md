# Thimble Finder (maquette)
Projet Android Kotlin (vues programmatiques, sans dépendance). Ouvrir dans Android Studio, lancer `app`.
Voir le message de synthèse pour ce qui fonctionne et ce qui reste à obtenir officiellement.

## Obtenir l'APK sans installer Android Studio (GitHub)
1. Crée un compte gratuit sur github.com, puis un nouveau dépôt (New repository).
2. Envoie tout le contenu de ce dossier (y compris le dossier caché `.github`) dans le dépôt.
   Astuce : sur la page du dépôt, « uploading an existing file », puis glisse-dépose les fichiers.
3. Onglet **Actions** > workflow **Build APK** (il démarre tout seul, ou clique sur *Run workflow*).
4. Quand il est vert (3 à 6 min), ouvre l'exécution et télécharge **ThimbleFinder-debug-apk** en bas de page.
5. Décompresse ce zip : `app-debug.apk` est à installer sur le téléphone.
